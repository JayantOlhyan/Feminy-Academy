# Feminy: softer landing-page refinement

Existing-page refinement. Brief uses the user's explicit requested changes and the existing approved project scope. Routine art direction is authored here; no user quotations are invented. This is not a new cinematic-site commission.

## Eight brief topics

1. Vibe, verbatim: "more rounded", "softer and safer". Existing reference: Yonko Creator OS.
2. Journey: retain the existing offer, work, courses, teacher, evidence and enquiry sequence. Authored within the current refinement scope.
3. Energy: calm opening, purposeful movement around work, quiet learning details, steady enquiry. Authored.
4. Emotion: approachable first impression, curiosity around the real work, trust in the teacher, clarity about the course, confidence to enquire. The strongest visual moment remains the artist-at-work frame in the hero rail.
5. Signature: From work to learning. Choosing a portfolio category updates a relevant course enquiry, so the work someone chooses leads into their learning interest. Authored, uses existing enquiry infrastructure.
6. Range: friendly photographic education. Rounded surfaces and warm existing palette; no new fictional imagery or figures.
7. Structure: distinct sections in natural document flow, retaining the existing page. No artificial pinned travel or replacement architecture.
8. Assets: exact pink-and-gold crest logo, supplied photography/client footage, locally available font files. No generation required.

## Grammar and journey

Adapted editorial gallery grammar: central readable offer, real photographic rail, clear course choices, teacher and evidence, static final enquiry. Sticky navigation retains real routes; native touch scroll remains available. Full cinematic grammars, split stages, or continuous worldflight would obstruct course reading on mobile.

## Feeling curve and peak

- Recognition: welcomed by friendly type, softer controls and the real crest.
- Curiosity: artist-at-work image subtly advances while neighbouring photographs move at different depths.
- Direction: course options arrive together with short restrained reveals.
- Trust: teacher and professional evidence stay easy to read.
- Agency: portfolio interest carries into the enquiry label/message.
- Confidence: final action stays still and fully visible.

Peak: "I can see the artist behind the work, and ask how to learn the part I care about." Lives in the media and category selection, with existing portfolio space rather than extra scroll distance.

Tell-someone sentence: It's the site where choosing the beauty work you like helps you ask about learning it.

## Scroll score

| Beat | Device | Purpose |
|---|---|---|
| Recognition | Short type entrance | Settle attention on headline and course action |
| Curiosity | Independent photo parallax and pausable rail pan | Establish the real work as the focus |
| Direction | Staggered course reveal | Make the options readable together |
| Trust | Static teacher/evidence with light section arrival | Avoid animating trust claims or numerical proof |
| Agency | Hover-preview crossfade and category-linked enquiry | Explore the supplied work without sound or a forced modal |
| Commitment | GSAP anchor navigation; static destination | Reach the requested information with an interruptible scroll |

GSAP is the sole animation runtime as requested. The skill engine is copied here unchanged for provenance; it is not loaded alongside GSAP to avoid competing scroll controllers. Mobile drops parallax/autoglide/hover video. Reduced motion disables movement and automatic previews. No full-page scroll hijacking. Automated gallery motion has a pause control and stops on user interaction, offscreen state, hidden tabs and dialogs.

## Layer contract

- Background: stationary blush surface.
- Typography: stable semantic headline after a short entrance; never hidden by photos.
- Focal plane: the real artist-at-work image, largest frame, smallest restrained depth movement.
- Adjacent planes: bridal and client frames at slightly different depths within clipped rounded frames.
- Foreground: labels and play controls remain fixed to their media cards.

The scene resolves into the existing course section; no duplicated subjects or generated cutouts. Static/reduced composition keeps the same meaning.
